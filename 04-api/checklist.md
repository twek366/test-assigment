API Test Checklist
Создание заказа
POST /api/v2/orders
| Проверка                                    | Ожидаемый результат       |
| ------------------------------------------- | ------------------------- |
| Создание заказа с валидными данными         | 201 Created               |
| Создание заказа без обязательного поля      | 400 Bad Request           |
| Создание заказа с некорректным типом данных | 400 Bad Request           |
| Создание дубликата заказа                   | согласно бизнес-логике    |
| Создание без токена                         | 401 Unauthorized          |
| Создание без прав                           | 403 Forbidden             |
| Создание при недоступной БД                 | 500 Internal Server Error |

Получение заказа
GET /api/v2/orders/{id}
| Проверка          | Ожидаемый результат |
| ----------------- | ------------------- |
| Существующий id   | 200 OK              |
| Несуществующий id | 404 Not Found       |
| Некорректный id   | 400 Bad Request     |
| Без токена        | 401 Unauthorized    |
| Нет прав доступа  | 403 Forbidden       |

Получение списка заказов
GET /api/v2/orders

Проверить:

200 OK
пагинацию
сортировку
фильтрацию
пустой список
большие объемы данных

Обновление заказа
PUT /api/v2/orders/{id}
| Проверка          | Ожидаемый результат |
| ----------------- | ------------------- |
| Полное обновление | 200 OK              |
| Несуществующий id | 404 Not Found       |
| Ошибка валидации  | 400 Bad Request     |
| Нет прав          | 403 Forbidden       |
| Без авторизации   | 401 Unauthorized    |

Частичное обновление
PATCH /api/v2/orders/{id}

Проверить:

изменение одного поля;
изменение нескольких полей;
изменение запрещенных полей;
пустое тело запроса.

Ожидаемые коды:

200 OK
400 Bad Request
403 Forbidden
404 Not Found

Удаление заказа
DELETE /api/v2/orders/{id}
| Проверка                      | Ожидаемый результат |
| ----------------------------- | ------------------- |
| Удаление существующего заказа | 204 No Content      |
| Повторное удаление            | 404 Not Found       |
| Нет прав                      | 403 Forbidden       |
| Без токена                    | 401 Unauthorized    |

Проверки бизнес-логики
Статусы заказа

Проверить допустимые переходы:

NEW
→ CONFIRMED
→ IN_PROGRESS
→ COMPLETED

Запрещено:

NEW → COMPLETED
COMPLETED → NEW
Идемпотентность

PUT:

повторный запрос не изменяет результат.

DELETE:

повторный вызов корректно обрабатывается.
Конкурентность

Проверить:

одновременное обновление заказа двумя пользователями;
конфликт версий;
потерю изменений.
Проверка структуры ответа

Проверить:

Content-Type: application/json
корректность JSON Schema
отсутствие внутренних технических полей
корректность даты и времени
Нагрузочные проверки

Проверить:

100 запросов/сек
массовое создание заказов
пагинацию на больших объемах данных
время ответа API
Негативные сценарии
Некорректный JSON

Запрос:

{
 "status":
}

Ожидание:

400 Bad Request
Передача строки вместо числа
{
 "weight":"abc"
}

Ожидание:

400 Bad Request
Ошибка БД

Ожидание:

500 Internal Server Error

Тело ответа не содержит stack trace.

BUG REPORT EXAMPLE
API-001
Title:
POST /api/v2/orders возвращает 500 вместо 400 при ошибке валидации

Severity:
Major

Priority:
High

Шаги:

1. Отправить POST запрос.
2. Не передавать обязательное поле customerId.

Фактический результат:

500 Internal Server Error

Ожидаемый результат:

400 Bad Request
