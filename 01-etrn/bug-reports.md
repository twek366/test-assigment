BUG-001
Title:
Система позволяет подписать ЭТрН без заполненного ИНН перевозчика

Severity:
Critical

Priority:
High

Предусловия:
Создается новая ЭТрН.

Шаги:

1. Создать ЭТрН.
2. Не заполнять ИНН перевозчика.
3. Нажать "Подписать".

Фактический результат:
Документ подписывается.

Ожидаемый результат:
Система должна заблокировать подписание и показать ошибку обязательного поля.
BUG-002
Title:
Разрешено перевести документ в статус "Разгружен" из статуса "Черновик"

Severity:
Major

Priority:
Medium

Шаги:

1. Создать ЭТрН.
2. Через API выполнить смену статуса на "Разгружен".

Фактический результат:
Статус изменен.

Ожидаемый результат:
Переход должен быть запрещен правилами бизнес-процесса.
