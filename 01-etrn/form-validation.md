Проверки по XSD

На основании формата ЭТрН ФНС проверяются:

Структура XML
наличие корневого элемента;
корректный namespace;
версия формата;
код документа.
Типы данных
Поле	Проверка
ИНН	длина 10/12
КПП	длина 9
Дата	ISO-формат
Масса	число >0
Стоимость	decimal
Ограничения
отсутствие запрещенных символов;
соблюдение maxLength;
соблюдение pattern;
отсутствие неизвестных XML-узлов.
XSD Validation

Позитив:

XML проходит валидацию.

Негатив:

XML не соответствует схеме.
Получена ошибка валидации.
Документ не отправляется.
