# Ревью ответа ИИ

## Что хорошо

- Покрыты основные позитивные сценарии.
- Есть проверки обязательных полей.
- Есть базовые негативные проверки.

## Что пропущено

### Логистические ограничения

ИИ не проверил:

- совпадение города отправления и назначения;
- маршруты без тарифа;
- международные маршруты;
- закрытые направления.

### Интеграционные проверки

Не учтены:

- таймаут API;
- 500 ошибка;
- некорректный JSON;
- повторная отправка запроса.

### UX

Не проверено:

- блокировка двойного клика;
- индикатор загрузки;
- сохранение введенных данных после ошибки.

### Избыточные проверки

Удалил бы:

- проверку вставки HTML в поле веса;
- проверку эмодзи в числовых полях.

Вероятность таких сценариев минимальна при использовании input[type=number].
