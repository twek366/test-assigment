Сгенерируй полный QA-чек-лист для тестирования формы создания заявки на перевозку.

Поля:

1. Город отправления (автокомплит).
2. Город назначения (автокомплит).
3. Вес груза (до 20000 кг).
4. Объем груза (до 82 м3).
5. Дата погрузки (не раньше текущей даты).
6. Кнопка "Рассчитать стоимость".

Необходимо:

- позитивные сценарии;
- негативные сценарии;
- граничные значения;
- UX-проверки;
- проверки интеграции с API;
- проверки ошибок.
